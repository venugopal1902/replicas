How a replica gets built

Behaviour is reverse engineered, code is written fresh. No proprietary source is copied.

1 · Map the surface

Read the public API, OpenAPI schema and agent docs. Capture real request and response pairs for every operation that matters.

2 · Trace the behaviour

Use REA and browser instrumentation to observe the live app: endpoints, state transitions, async job shapes, error semantics.

3 · Write it clean

Implement the same contracts in our own code. Compatibility is behavioural, not copy-pasted.

4 · Prove it works

End-to-end tests hit the real ASGI app: publish, poll status, verify credits, list MCP tools. Green suite or it does not ship.
