Geckoboard Engine

Push your own datasets, compose widgets, rotate dashboards on a TV. No $79/mo per screen.

Replaces Geckoboard Version 0.1.0 License MIT Runtime Python 3.12

Overview#

Geckoboard charges $79 to $319 a month to put your own numbers on a wall. This engine keeps the part that matters: define a dataset schema, push rows with append or replace semantics through a dataset API key, compose widgets that read those rows, preview a dashboard, and run a TV rotation that cycles dashboards on a public URL. Unauthenticated admin access is refused, malformed field types are rejected, oversized bodies are refused, and the dashboard UI loads no external assets.

replaces Geckoboardv0.1.0MITPython 3.12

What you get

  • 31/31 checks passing on a clean run
  • Dataset push with append vs replace semantics
  • Separate dataset API key, rotatable via admin

Interface#

Dashboard console at / and public TV rotation at /tv/<public_id> on port 8670.

Install#

From a clean machine to a running server in four commands.

Requirements

  • Python 3.12 or newer
  • uv (Astral)
  • GECKOBOARD_ADMIN_PASSWORD and GECKOBOARD_DATASET_API_KEY set before first start

Step 1 · Clone

Get the source.

git clone https://github.com/venugopal1902/replicas.git
cd replicas/services/geckoboard-engine

Step 2 · Install

Create the environment.

uv sync

Step 3 · Set first-boot credentials

Both are required; nothing is generated or logged.

export GECKOBOARD_ADMIN_PASSWORD='choose-a-long-unique-password'
export GECKOBOARD_DATASET_API_KEY="$(openssl rand -hex 24)"

Step 4 · Run

Console on port 8670.

uv run python scripts/run_server.py

Run the suite with a free test port

cd services/geckoboard-engine
GECKOBOARD_TEST_PORT=8641 uv run --with pytest --with httpx --with pillow pytest tests/ -q

Usage#

Push rows into a dataset

Append and replace differ: append adds rows, replace swaps the set. The dataset API key is separate from the admin session.

curl -s -X POST http://127.0.0.1:8670/api/datasets/$DATASET/data \
  -H "Authorization: Bearer $DATASET_KEY" -H 'Content-Type: application/json' \
  -d '{"data":[{"label":"signups","value":42}]}'

Operational notes#

Read before going live. These are the things that break in production.
  • Both first-boot credentials are required; nothing is generated and nothing is printed to logs.
  • Connectors to Shopify, Zendesk or Aircall are not implemented: you push data yourself.
  • The suite refuses to run on a port that is already listening, so it never disturbs a live instance.

FAQ#

Do I need a data source integration?

No. You push rows to the dataset API yourself, which is what the paid product's custom-dataset feature does.

Can it run on a TV?

Yes. A rotation has a public URL and a /tv/ page that cycles the dashboards in it.
